# 蓝鲸游戏厅 · 知识库

程序员爱好小组围绕 **DeepSeek 拟人形象（蓝鲸）** 制作的小游戏合集：格斗、闯关、塔防（植物大战僵尸式）、跑图逃生等类型，全部整合进同一个网页大厅。

## 项目速览

| 项 | 内容 |
| --- | --- |
| 主题 | DeepSeek 拟人形象（蓝鲸）小游戏合集 |
| 成员 | 程序员爱好小组，多人并行独立开发 |
| 形态 | 单网页大厅（index.html）+ 各游戏以 iframe 岛集成 |
| 仓库布局 | 单仓 monorepo，每个游戏独占 `games/<id>/` |
| 部署 | 整仓纯静态站点，推荐 GitHub Pages，可随时迁移任意静态托管 |

## 文档地图

- [[技术框架定稿]] —— 架构决策记录（ADR）：整合方案、技术选型、被否方案与理由。**新成员先读这篇**
- [[游戏接入指南]] —— 开发一个新游戏并合并进大厅的完整契约：games.json 字段、postMessage 协议、BFShell API、自测清单、常见坑
- [[鲸鱼娘格斗设计案]] —— 鲸鱼娘 1v1 格斗（暂定名《杀鲸霸拳》）玩法设计：Token 槽、爆气·烧 Token、必杀·杀鲸霸拳、宿敌蓝总 BO3 与里程碑，**已立项开发（M0 通过）**
